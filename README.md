# ইউনিয়ন পরিষদ অটোমেশন সিস্টেম (Union Parishad Automation System)

এটি একটি পূর্ণাঙ্গ ডিজিটাল সমাধান যা Google Workspace (Sheets, Docs, Apps Script) এবং Gemini AI ব্যবহার করে ইউনিয়ন পরিষদের ৪০+ ধরনের প্রত্যয়নপত্র স্বয়ংক্রিয়ভাবে তৈরি, সংরক্ষণ এবং যাচাই করতে সক্ষম।

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

*   **স্মার্ট ডাটা ইনটেক:** Google Form বা ওয়েবসাইটের মাধ্যমে নাগরিক তথ্য গ্রহণ।
*   **Gemini AI ইন্টিগ্রেশন:** অগোছালো ইনপুট থেকে দাপ্তরিক ভাষায় নির্ভুল বিবরণী (body text) তৈরি।
*   **ডাইনামিক টেমপ্লেট:** একটি মাত্র Google Doc টেমপ্লেট ব্যবহার করে সব ধরনের সনদ তৈরি (ওয়ারিশ, চারিত্রিক, ভূমিহীন ইত্যাদি)।
*   **স্বয়ংক্রিয় ভেরিফিকেশন:** প্রতিটি সনদে একটি ইউনিক QR কোড থাকে যা স্ক্যান করলে তাৎক্ষণিকভাবে সত্যতা যাচাই করা যায়।
*   **সম্পূর্ণ নিয়ন্ত্রণ:** অ্যাডমিন প্যানেল থেকে লোগো, চেয়ারম্যানের নাম, ঠিকানা এবং এআই প্রম্পট পরিবর্তন করার সুবিধা।

## 📂 ফাইল স্ট্রাকচার (Repository Structure)

এই রেপোজিটরিতে মূলত নিচের ফাইলগুলো থাকবে:

*   `/src/Code.gs`: ব্যাকএন্ড লজিক, পিডিএফ জেনারেশন এবং ডাটাবেস হ্যান্ডলিং।
*   `/src/Gemini.gs`: Gemini AI কানেক্টর কোড।
*   `/src/Index.html`: ইউজার ইন্টারফেস (UI) এবং ফ্রন্টএন্ড কোড।
*   `README.md`: প্রজেক্ট সেটআপ ও ব্যবহার নির্দেশিকা।

## 🛠 সেটআপ নির্দেশাবলী (Installation Guide)

আপনার নিজস্ব ইউনিয়ন পরিষদের জন্য এই সিস্টেমটি চালু করতে নিচের ধাপগুলো অনুসরণ করুন:

### ১. গুগল শিট ও অ্যাপস স্ক্রিপ্ট তৈরি
1. একটি নতুন [Google Sheet](https://sheets.new) খুলুন।
2. মেনু থেকে **Extensions** > **Apps Script**-এ ক্লিক করুন।
3. প্রজেক্টের নাম দিন "UP Automation System"।
4. রেপোজিটরি থেকে `Code.gs`, `Gemini.gs`, এবং `Index.html` কোডগুলো সংশ্লিষ্ট ফাইলে কপি-পেস্ট করুন। (Apps Script-এ HTML ফাইল তৈরির সময় নাম অবশ্যই `Index` দিন)।

### ২. Gemini API Key সেটআপ
1. [Google AI Studio](https://aistudio.google.com/) থেকে একটি ফ্রি API Key সংগ্রহ করুন।
2. Apps Script এডিটরে **Project Settings** (গিয়ার আইকন) > **Script Properties**-এ যান।
3. `Add script property` ক্লিক করে Property-তে `GEMINI_API_KEY` এবং Value-তে আপনার প্রাপ্ত কি-টি বসিয়ে সেভ করুন।

### ৩. কনফিগারেশন আপডেট
`Code.gs` ফাইলের উপরে থাকা `CONFIG` অবজেক্টে আপনার Google Doc টেমপ্লেট আইডি এবং ড্রাইভ ফোল্ডার আইডি দিন।

### ৪. ডিপ্লয়মেন্ট (Deployment)
1. স্ক্রিনটির উপরে ডানপাশে **Deploy** > **New Deployment** ক্লিক করুন।
2. Type থেকে **Web App** নির্বাচন করুন।
3. 'Execute as' এ **Me** এবং 'Who has access' এ **Anyone** নির্বাচন করুন।
4. **Deploy** বাটনে ক্লিক করুন। প্রাপ্ত URL-টিই আপনার অটোমেশন সিস্টেমের লাইভ ঠিকানা।
